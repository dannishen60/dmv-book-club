# DMV Weekly Book Club

Website for the DMV Weekly Book Club, hosted by Danni. Meets online every Tuesday at 8 pm Eastern.

- `index.html` is the page source (also published as a Claude artifact).
- `build.py` wraps it into a complete document in `docs/`, which GitHub Pages serves.
- `covers/` holds book covers; `photos/` holds the public-domain paintings used as backgrounds.

To update the site: edit `index.html`, run `python build.py`, commit and push.
